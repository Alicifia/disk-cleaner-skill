# disk-cleaner-skill

一个给 AI Agent 使用的**安全磁盘清理技能**：让 AI 按"先看名字判断 → 必要时只读片段确认 → 删除前列清单等用户确认"的三层安全流程，清理任意分区或文件夹中的垃圾文件，**显著节省 token 消耗**。

## 为什么能节省 token 消耗

这个声明是真实成立的，原因如下：

1. **名字优先分层筛查**：AI 默认的暴力做法是递归遍历并读取大量文件内容来判断是不是垃圾，每个文件的内容都会进入上下文窗口。本技能强制"先看文件夹/文件名字分类"——程序目录、个人数据目录凭名字直接跳过，完全不展开、不读取，从源头上避免把成千上万行无关内容灌进上下文。
2. **片段式读取**：只有名字无法判断身份时才读文件，且只读前 5–10 行，确认类型（日志/缓存/代码）立即停止，而不是读完整文件。
3. **小项合并**：几 MB 以下的小文件夹合并为"小项"统一汇报，不为它们逐个展开目录。

实测效果：清理一台 600 GB、已用 318 GB 的 Windows 系统盘，全程只读了 4 个文件的片段（每个不超过 10 行），其余判断全部基于文件名和大小完成。

## 安全设计

清理类技能最大的风险是误删，本技能用三层防线控制：

- **三档清单**：扫描结果分为"建议清理 / 需用户判断 ⚠️ / 不建议动"，可能是用户内容（代码、草稿、配置）的一律标 ⚠️ 单独请示。
- **确认后删**：任何删除执行前，必须把具体清单（路径 + 大小 + 身份说明）展示给用户，等明确同意。
- **内置黑名单**：`Windows\Installer`（MSI 卸载缓存）、`WinSxS`、注册表配置单元、虚拟内存文件、个人文件等永不删除。

## 安装

把整个文件夹（含 `SKILL.md`）放入你的技能目录即可：

- Kimi Work / Kimi CLI：`<skills-root>/disk-cleaner/SKILL.md`
- Claude Code 兼容路径：`~/.config/agents/skills/disk-cleaner/` 或 `~/.claude/skills/disk-cleaner/`

## 使用

安装后对 AI 说自然语言即可触发：

- "清理 C 盘"
- "帮我清理 D 盘，先列清单"
- "清理这个文件夹：D:\\Downloads"

AI 会按 6 步流程执行：定范围记基线 → 按名字分层筛查 → 测量大小 → 读片段确认 → 出三档清单等确认 → 删除并验收。

## 适用范围

- 目标：任意磁盘分区（C:\、D:\…）或任意指定文件夹
- 平台：内置的已知安全目标/黑名单以 Windows 为主，流程本身平台无关
